# E-Commerce — Terminology

| Term | Meaning |
|---|---|
| OMS | Order Management System — tracks an order through its lifecycle |
| SKU | Stock Keeping Unit — a unique identifier for a specific sellable item |
| Overselling | Selling more units than are actually in stock |
| Stock reservation | Holding stock for an in-progress order before payment confirms |
| Cart abandonment | A customer starts checkout but never completes it (not modeled in this repository — no persistent cart) |
| Fulfillment | The process of picking, packing, and shipping an order (not implemented here) |
