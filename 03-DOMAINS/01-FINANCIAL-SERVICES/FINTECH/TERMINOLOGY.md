# FinTech — Terminology

| Term | Meaning |
|---|---|
| KYC | Know Your Customer — identity verification before allowing transactions |
| AML | Anti-Money Laundering — monitoring for suspicious transaction patterns |
| Ledger | Append-only record of every balance-affecting entry; source of truth over a cached balance field |
| Settlement | The process of finalizing a transaction so funds actually move between parties |
| Reconciliation | Comparing internal records against an external system's records to detect drift |
| Spread | Difference between buy and sell price in a trading context |
| Limit order | An order to buy/sell only at a specified price or better |
| Market order | An order to buy/sell immediately at the best available price |
| Float | Balance a platform holds on behalf of customers before it's withdrawn/settled |
| Double-spend | The specific failure mode where the same balance is used to satisfy two transactions (see `22-SYSTEM-PATTERNS/CONCURRENCY.md`) |
