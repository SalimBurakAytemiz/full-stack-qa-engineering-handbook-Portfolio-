## Why this stays at D0

Writing a full domain model, risk catalog, and test strategy for a
domain with zero professional or repository grounding would be pure
invention dressed up as documentation — exactly what Section 51 ("no
AI-style filler," "no meaningless abstractions") warns against. This
page is intentionally minimal until there is a real reason (a lab, a
case, a confirmed learning exercise) to expand it.
