# 07-INTERVIEW

Two distinct question sets, per Section 44's separation:

1. **General Full Stack QA questions** — real interview questions any
   candidate could be asked, with real technical answers grounded in this
   repository's code. Not about Salim specifically.
2. **Profile-specific questions** — questions an interviewer would ask
   *about Salim's own background*, answered strictly from the Digital
   Twin's registries (no invented experience, no collapsing knowledge/
   professional/repository into one claim).

## Source of truth

Every answer in 15-19 must trace to a fact already recorded in
`01-SALIM-BURAK-DIGITAL-TWIN/registry/*.yaml`. If a question's honest
answer is "I don't know" or "I haven't done that professionally," the
file says so — that is the entire point of Section 44's separation from
the general question set, where a wrong or invented answer would be a
technical error, not a claim-integrity violation.
